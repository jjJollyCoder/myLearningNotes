    # 💼 项目：账单分类与训练系统

## 📌 项目目标

- 将支付宝、微信、信用卡账单进行统一导入
- 使用关键词规则进行自动分类
- 支持大类与细类的双层分类逻辑
- 最终形成清晰的可视化消费报告或月度汇总

---

## 📂 项目结构

```bash
bill-classifier/
├── src/
│   ├── config.py
│   ├── reader.py
│   ├── load_rule.py
│   ├── classify.py
│   ├── utils.py
│   └── main_classify.py
├── rules/
│   └── rules_alipay.json
└── data/
    └── my_alipay_bill_2025.csv

    🧱 模块说明

    模块 作用
    config.py 存放路径常量、平台名等配置
    reader.py 加载 CSV/PDF 表格数据，统一为 DataFrame
    load_rule.py 加载并解析 JSON 格式的规则文件
    classify.py 分类核心逻辑：关键词判断、字段组合等
    utils.py 金额处理、时间格式转换、清洗函数
    main_classify.py 执行主入口，可命令行调用或 Jupyter 测试

    🚧 遇到问题与解决

    ❌ 问题

    • 支付宝 vs 微信的字段不一致（如“交易对方” vs “商户”）
    • 规则文件中类别层次不统一
    • 分类逻辑过于“硬编码”
    • 批量处理不方便，路径多次修改

    ✅ 解决方案

    • 提取字段映射逻辑，按平台区分处理
    • 用 JSON 存规则，按平台加载匹配规则集
    • 分类结果添加备注、调试信息便于排查
    • 主入口通过 CLI 支持文件路径传参

    🧭 运行方式（示例）

    # 直接运行
python src/main_classify.py

# 推荐方式（保持相对导入）
python -m src.main_classify --input ./data/my_bill.csv
